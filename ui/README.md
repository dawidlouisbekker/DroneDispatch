# UI apps

Front-ends for Drone Drop. Each folder is an independent app with its own dependencies.

| App | What it is | Status |
|---|---|---|
| [app/](app/README.md) | Expo app for web, Android and iOS: the customer live map and ordering screens, plus the merchant portal | In progress |
| `devops/` | Operations dashboard built on the Aspire orchestrator dashboard | Planned |

There's no shared workspace yet. Add a pnpm workspace here when a second app needs shared code.
